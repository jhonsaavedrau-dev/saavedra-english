# saavedra english · Repaso de Interchange 3

App de repaso para los estudiantes de inglés de Jhon Saavedra. Cubre las 16 unidades de *Interchange 5th edition, Level 3* (Cambridge) con explicaciones en español, vocabulario con audio, práctica, retos, speaking y un cuaderno de errores.

Enlace: https://jhonsaavedrau-dev.github.io/saavedra-english/

## Cómo se actualiza

No se edita aquí. La fuente está en `PROYECTOS/tutorias-ingles/`: `repaso.html`, `unidades.js` e `img/`. Para publicar un cambio:

```
cd PROYECTOS/tutorias-ingles
python publicar-web.py "qué cambió"
```

El script copia los archivos a esta carpeta, hace commit y push. GitHub Pages actualiza el enlace en uno o dos minutos.

El progreso de cada estudiante se guarda en su propio navegador.

Las explicaciones y los ejercicios son originales. No reproducen el texto del libro.
